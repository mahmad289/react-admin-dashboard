# pseudo_code/

Collection of Python-style pseudo code files illustrating common data-structure and algorithm patterns. Used as a learning reference alongside the React project.

## Contents

- `graph_traversal.py` – Pseudo code for graph traversal algorithms (e.g. BFS and DFS). Added on the `sudo-code-graph-traversal` branch and merged in PR #2.
- `linked_list.py` – Pseudo code for a singly linked list implementation with typical operations (insert, delete, search, traverse).

## Notes

- These files are for reference; they are not imported by the React application.
- New algorithms can be added here as individual `.py` files. Please keep each file self-contained and add a short docstring at the top describing the algorithm and its complexity.
