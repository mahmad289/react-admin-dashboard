# Project Help & Documentation

This `help` folder contains directory-wise information about the React Admin Dashboard project. It is intended as a quick reference for developers to understand the layout and purpose of each top-level folder in this repository.

## Project Overview

**Name:** react-admin
**Version:** 0.1.0
**Framework:** React 18 (bootstrapped with Create React App)
**UI Library:** Material UI (MUI) v5, with Emotion for styling
**Charts:** Nivo (bar, line, pie, geo)
**Calendar:** FullCalendar
**Forms:** Formik + Yup
**Routing:** react-router-dom v6
**Sidebar:** react-pro-sidebar

## Available Scripts

- `npm start` – Start development server on http://localhost:3000
- `npm run build` – Build production bundle into `build/`
- `npm test` – Run the interactive test runner
- `npm run eject` – Eject CRA configuration (one-way)
