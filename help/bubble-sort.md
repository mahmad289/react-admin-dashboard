# bubble-sort/

Standalone folder containing pseudo code for the bubble sort algorithm in Python.

## Contents

- `bubble_sort.py` – A Python-style pseudo code walkthrough of the bubble sort algorithm. Intended as a learning reference, not as an imported module.

## About bubble sort

Bubble sort repeatedly steps through a list, compares adjacent items and swaps them if they are in the wrong order. The pass through the list is repeated until no swaps are needed.

- Time complexity: O(n²) average and worst case, O(n) best case (already sorted).
- Space complexity: O(1) – sorts in place.
